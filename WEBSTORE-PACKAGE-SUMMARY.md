### Immediate Tasks (Before Submission):

**1. Create Screenshots (15-20 minutes)**
- Follow [SCREENSHOT-GUIDE.md](SCREENSHOT-GUIDE.md)
- Create at least 1 screenshot (recommend 3-5)
- Required: Zipcode lookup popup and Tax calculation button
- Blur any sensitive customer/API data

**2. Prepare Icon (2 minutes)**
- Open `src/icon-50px.png`
- Resize to 128x128 pixels
- Save as `icon-128.png`

**3. Host Privacy Policy (5 minutes)**
- Choose hosting method (website, GitHub Pages, Google Sites)
- Upload [PRIVACY-POLICY.md](PRIVACY-POLICY.md) content
- Get the public URL

**4. Create Developer Account (5 minutes)**
- Visit: https://chrome.google.com/webstore/devconsole
- Sign in with Google account
- Pay $5 registration fee (one-time)

---

### Submission Process (30-45 minutes):

**5. Upload Extension**
- Go to Developer Dashboard
- Click "New Item"
- Upload: `releases/brightpearl-taxjar-v2.0.0.zip`

**6. Fill Store Listing**
- Open [WEBSTORE-LISTING.md](WEBSTORE-LISTING.md)
- Copy/paste all content into Web Store form
- Upload screenshots and icon
- Enter privacy policy URL

**7. Set to Unlisted** ⚠️ **CRITICAL**
- Distribution tab → Visibility → Select "Unlisted"
- This keeps it private (only accessible via direct link)

**8. Submit for Review**
- Review all tabs for errors
- Click "Submit for review"
- Wait 1-3 business days for Google approval

## ❓ Questions?

### "Do I have to use Chrome Web Store?"

**No!** You have 3 options:
1. **Chrome Web Store (Unlisted)** - Easiest, no Developer mode, $5 fee
2. **Enterprise Policy** - For IT-managed organizations, free but complex
3. **Developer Mode** - Free but requires Developer mode (less professional)

### "Can I keep it completely private?"

**Yes!** With Unlisted visibility:
- Not searchable in Chrome Web Store
- Only accessible via direct link
- You control who gets the link
- Can't be found without the link

### "What if Google rejects my submission?"

- They'll email specific reasons
- Fix the issues mentioned
- Resubmit (no additional fee)
- Common issues: privacy policy, permission justifications, screenshots

### "Can I unpublish later?"

**Yes!** You can:
- Unpublish at any time from Developer Dashboard
- Stops new installs
- Existing installations remain but won't update
- Can republish later
